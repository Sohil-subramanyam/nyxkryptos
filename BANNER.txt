┌─────────────────────────────────────────────────────────────────────────────┐
│  HOW IT WORKS                                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. You create a vault with your secrets                                   │
│     ↓                                                                       │
│  2. System generates random 256-bit encryption key                         │
│     ↓                                                                       │
│  3. Secrets are encrypted with AES-256                                     │
│     ↓                                                                       │
│  4. Key is split into N shares (Shamir's algorithm)                        │
│     ↓                                                                       │
│  5. Each share is hidden in AI-generated artwork (steganography)           │
│     ↓                                                                       │
│  6. Artifacts are distributed to trusted guardians                         │
│     ↓                                                                       │
│  7. To unlock: collect K artifacts (threshold)                            │
│     ↓                                                                       │
│  8. System extracts shares and reconstructs key                            │
│     ↓                                                                       │
│  9. Data is decrypted and displayed                                        │
│                                                                             │
│  🔐 Security: No one can decrypt without K artifacts (even creators!)      │
│  🎨 Steganography: Keys hidden in artwork, invisible to human eye         │
│  🚫 No servers: All encryption happens in browser                         │
│                                                                             │
